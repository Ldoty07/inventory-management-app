This app allows users to browse, add, edit, and delete products. Data is stored in and retrieved from a supabase database.

To set up the app, you first need to make sure you have Node.js installed. After it is installed, you will need to download the files, navigate to the folder they are in using Command Prompt, and run these scripts:
    npm install
    npm run dev

This will run a local development server that you can access by holding ctrl and clicking on the local address in the terminal.
